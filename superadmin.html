Not a Super Admin

  1. Open the Firebase console with the blue button below. You land on Build → Firestore Database. You will see your existing database named (default). Leave it alone.
  2. Create a second database. At the top, click the database dropdown that says (default) and choose Add database.
  3. Name it exactly central (lowercase), in the Database ID box. Pick the same location as your default database. You can't change it later. Choose Start in production mode, then Create and wait about a minute.
  4. Publish the rules. Check the dropdown now says central. Open the Rules tab, select everything in the editor and delete it. Press Copy security rules below, paste, then click Publish.
  5. Come back here and press Reload. You should now see "Not a Super Admin" with a long user ID. That is expected, and the next step fixes it.
  6. Add yourself. In the console, with central selected, go to the Data tab → Start collection. Collection ID: superAdmins. Document ID: paste your user ID (don't use Auto-ID). Add one field: email (string) = your email. Save, then reload this page.

If the console asks you to upgrade to the Blaze (paid) plan before adding a second database, stop and tell me. I can switch the Super Admin data into your existing database instead.
